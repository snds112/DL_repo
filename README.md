# Collection des TP du module Deep Learning et travail personnel

Ce dépôt regroupe les supports de cours et les énoncés de travaux pratiques (TP) du module **Deep Learning** ainsi que mon travail personnel réalisé dans ce cadre.
---

## 📚 Contenu du dépôt

### Cours théoriques

| Fichier | Description |
|--------|-------------|
| `Cours #1 and Lab #1 - Neural Networks.pdf` | Introduction historique aux réseaux de neurones : McCulloch-Pitts, règle de Hebb, Perceptron, ADALINE. Exercices théoriques et implémentations Python. |
| `Cours #2 .pdf` | Introduction aux réseaux de neurones profonds : rétropropagation, fonctions d’activation, fonctions de perte, optimiseurs, hyperparamètres, régularisation, premiers pas avec TensorFlow/Keras. |
| `Cours #3 - Convolutional Neural Network.pdf` | Réseaux de neurones convolutifs (CNN) : convolution, padding, stride, pooling, architectures majeures (LeNet, AlexNet, VGG, ResNet, etc.), exemple complet sur CIFAR-10. |
| `Cours #4 - RNN .pdf` | Réseaux de neurones récurrents (RNN) : connexions récurrentes, BPTT, LSTM, GRU, RNN bidirectionnels, encodeur-décodeur, mécanismes d’attention, applications. |

### Travaux pratiques (TP)

| Fichier | Description |
|--------|-------------|
| `Practical Work – Lab 2.pdf` | Introduction aux réseaux de neurones profonds avec Keras/TensorFlow. Classification binaire, validation croisée, recherche d’hyperparamètres, comparaison d’optimiseurs, régularisation, et mini-projets. |
| `Practical Work – Lab 3.pdf` | TP sur les CNN : premiers modèles sur MNIST, Fashion-MNIST, CIFAR-10, data augmentation, visualisation de cartes de caractéristiques, callbacks, batch normalization, transfert d’apprentissage, et mini-projets. |
| `Practical Work – Lab 4.pdf` | TP sur les RNN : prétraitement de texte, SimpleRNN, LSTM, GRU, embeddings, RNN bidirectionnels, génération de texte, prévision de séries temporelles, encodeur-décodeur, attention, et mini-projets. |

### Travail personnel

Ce dépôt contient également mon travail personnel : implémentations, expérimentations, analyses et résultats obtenus dans le cadre de ce module.
